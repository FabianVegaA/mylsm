# LSM Key-Value Store Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a durable, write-optimized tiered LSM key-value store in Bend 2, with every behavior covered by a proven law.

**Architecture:** Generic ordered-key core (`String` first) with MemTable + checksummed WAL + tiered SSTables + Manifest + merge iterator; writes never read, commits ack only after fsync, flush/compaction run in background.

**Tech Stack:** Bend 2.0.4 (minimum floor), Base library only (no extra packages, no foreign C/JS effects), git.

**Spec:** `docs/superpowers/specs/2026-09-17-lsm-bend-design.md`

## Global Constraints

- Bend 2.0.4 is the version floor (`bend --version` must report 2.0.4+ before any task).
- No `@unsafe` def anywhere in the repo — core, proofs, and harness alike.
- Affine by default; `+` annotations only on `Data` values where sharing is needed.
- All recursion structurally decreasing or `Nat`-fuel-bounded.
- Every commit must pass `bend PROOF.bend` ("All terms check."); a red gate blocks the commit.
- One fsync per batch commit (group commit); never one sync per key.
- Compaction fan-in default T = 4 tables per level; MemTable entry cap MEMTABLE_ENTRY_CAP = 4096 (both tunable only with a re-recorded benchmark baseline).
- Host effects limited to Base `File`/`IO` operations; proofs stay in pure Bend.
- Array indexes explicitly bounds-checked against known size; wraparound is never load-bearing; no `Array.clone` aliasing.

```python
# src/MemTable.bend
import Base
import ./Keys.bend as Keys

type Entry is Data:
  Entry{key: String, val: Maybe<String>}

type MemTable is Data:
  MT{entries: List<Entry>}

def empty() -> MemTable:
  MT{Nil{}}

def put(t: MemTable, k: String, v: String) -> MemTable:
  insert_sorted(t, Entry{k, Some{v}})

def del(t: MemTable, k: String) -> MemTable:
  insert_sorted(t, Entry{k, None{}})

def get(t: MemTable, k: String) -> Maybe<String>:
  match t:
    case MT{entries}:
      scan_get(entries, k)

def count(t: MemTable) -> Nat:
  match t:
    case MT{entries}:
      List.length(&2, Entry, entries)
```

`insert_sorted` keeps `entries` strictly ordered by `Keys.cmp`, replacing any existing entry with the same key; `scan_get` walks the list, returning the entry's `val` (`None{}` = tombstone = not-found) on key match and `None{}` when passing the key's sort position. Prove `mt_ryw`/`mt_del` by case analysis on the insertion walk in `PROOF.bend`.

### Task 4: SSTable writer/reader + Bloom filter

- [ ] **Step 1: Write the failing laws**

```python
# append to LAWS.bend
import ./src/Sstable.bend as Sstable

# LAW: table lookup agrees with the sorted source list
law sst_lookup:
  for e: List<MemTable.Entry>
  for k: String
  {Sstable.lookup(Sstable.build(e), k) == MemTable.get(MemTable.MT{e}, k) : Maybe<String>}

# LAW: bloom never rejects a present key
law bloom_safe:
  for e: List<MemTable.Entry>
  for k: String
  for v: String
  {Sstable.maybe_present(Sstable.build(Con{MemTable.Entry{k, Some{v}}, e}), k) == True{} : Bool}

# LAW: filter bits follow the Monkey schedule (spec 3.4)
law bloom_schedule:
  for lvl: Nat
  for n: Nat
  {Sstable.table_bits(Sstable.build_sized(lvl, n, Nil{})) == Sstable.bloom_bits(lvl, n) : Nat}
```

(`Sstable.build_sized(lvl, n, entries)` is the sized constructor all builders use; `table_bits` reads back the allocated filter size. Pin the `bloom_bits` closed form against Monkey (Dayan et al., SIGMOD'17) before proving — the law locks whatever the spec's BLOOM_TOTAL_BITS budget implies.)

# bench/bench.bend
import Base
import ../src/Db.bend as Db

def put_loop(h: Db.Handle, n: Nat) -> IO<Db.Handle>:
  match n:
    case 0n:
      IO.pure(Db.Handle, h)
    case 1n+m:
      do IO<Db.Handle>:
        h2 : Db.Handle <- Db.put(h, Nat.show(n), "v")
        put_loop(h2, m)

def main() -> IO(Unit):
  do IO<Unit>:
    h : Db.Handle <- Db.open("bench-data")
    t0 : U32 <- IO.now_ms()
    h2 : Db.Handle <- put_loop(h, 20000n)
    t1 : U32 <- IO.now_ms()
