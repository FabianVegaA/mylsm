# MyLSM 0.6.0.2

MyLSM 0.6.0.2 updates the pinned environment to Bend 2.0.40 and ez 1.15.0
and fixes a native owner crash exposed by the new Bend runtime.

## Compatibility fix

The polling effect constructed readiness lists without preparing child references
for shared consumption. With Bend 2.0.40, a client connecting to the owner could
trigger a reference-count `runtime fail-stop`. The effect now uses Bend's IO
constructor helper for events and list nodes. A regression fixture shares the
returned events and checks their count, identity and flags; it fails before the
fix and passes afterwards. The corrected fixture also passes on Bend 2.0.39.

The Nix environment pins Bend at `222de9901d4e3551c2b347da02e02a10098a28b2`
and ez at `376d36dadb613d957baed1521036c6f10c398a91`.
The Bend release tag itself still packages 2.0.39; the pinned follow-up commit
packages 2.0.40. Vendored SHA source was reformatted to satisfy the existing
200-character gate without changing executable tokens or its trust limitations.

## Upgrading

Rebuild native binaries with the updated environment. Public APIs, storage
formats and Hub dependency hashes are unchanged. Existing 0.6 databases do not
need migration. The migration requirements for older formats remain unchanged.

The Git tag is `v0.6.0.2`. The library is also published on Bend Hub:

```bend
import mylsm-lsm-store@0.6.0.2/mylsm.bend as MyLSM
```

The published package hash is `0x7586b743ff7fd05e412d5115859629b6`.
The publication contains 156 files (1,460,448 bytes).

## Validation

Darwin 25.6.0 arm64, using the pinned Nix environment:

- **84/84 formal modules pass** with `--verdict`, zero failures and zero timeouts.
- **14/14 runtime matrix cases pass**, covering owner options, generations,
  deadlines, fairness, backpressure, resource budgets, endpoint lifecycle and restore publication.
- **16 storage/host checks pass**, including positioned reads, truncated/corrupt
  SSTs, UTF-8, WAL recovery, backup, migration, crash checkpoints and Bun FFI.
- **Six backend checks pass:** native/Node/Bun effects and all three public
  examples compiled to JavaScript and run under Bun.
- Decoder corpora pass: **1,000,000 seeded inputs** and **708 directed cases**.
- Full lint and **`nix flake check` pass**, including the installed CLI's
  persistent REPL reads and supervised thread restart.

See the [compatibility evidence](../../bench/results/mylsm-0.6.0.2-compatibility.md)
for commands, results and the regression diagnosis. Raw logs and the tested-source
manifest are attached to the GitHub release as `mylsm-0.6.0.2-validation.tar.gz`.

## Limits

This release's compatibility evidence is for Darwin arm64. Linux and GPU
compatibility require separate runs. The JavaScript effects still do not support
the owner's Unix sockets; Node capability-rejection tests are not full database
acceptance. Runtime fixtures and seeded corpora are empirical evidence, not
general proofs. Formal laws do not prove Bend Base, the compiler, host IO or
filesystem durability. Existing performance limitations remain unchanged.
